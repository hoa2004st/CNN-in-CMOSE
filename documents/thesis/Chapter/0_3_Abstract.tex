\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}

Reading student engagement from video automatically is a useful tool for online and hybrid classes, yet it is hard: engagement labels are \emph{ordinal} (Highly-Disengage, Disengage, Engage, Highly-Engage), badly \emph{imbalanced}, and subjective, and models are rarely tested on any dataset other than the one they were trained on.
This thesis studies how to classify engagement from facial-behaviour features that OpenFace reads from each frame, and motion features that I3D reads from the whole clip. It makes three contributions: a hybrid model that splits the facial features into meaningful groups, a private test set we collected ourselves, and an honest study across datasets.
A study of single-encoder baselines first sets how models are measured, before any model is compared. The six candidate metrics clearly disagree on the best model, a disagreement the cross-dataset study later settles against accuracy. For this reason, \textbf{quadratic-weighted kappa (QWK) is used as the single metric for selecting the best model}, with macro-accuracy and macro-MAE kept as secondary balanced checks. The loss is shown to trade QWK against those balanced metrics, so cross-entropy, which gives the highest QWK, is used for development. A clip-level error analysis also finds that the OpenFace and I3D feature families make different errors, which is why they are combined.

First, the thesis proposes a \textbf{feature-group hybrid temporal architecture}.
Instead of feeding all 709 OpenFace features into one model, the features are split into five meaningful groups (gaze, eye landmarks, face landmarks, head pose, and action units), and each group is given its own temporal encoder (a Temporal Convolutional Network, a Transformer, or an LSTM), optionally combined with an I3D motion stream and trained with a small head on each stream.
A full ablation over all 243 per-group encoder choices, with and without I3D, shows that the I3D hybrid family sits above the best single-encoder baseline on the CMOSE test set (median quadratic-weighted kappa, QWK, of 0.553 against 0.537; best 0.605), that the strongest configurations mix encoder types, and that the only group with a clear encoder preference is \textbf{head pose, which prefers a TCN}.

Second, it introduces a \textbf{private test set of webcam clips that we collected and hand-labelled}, made with the same OpenFace/I3D pipeline as the public datasets and kept only for testing. It tests how well a model works on real students recorded on their own webcams, with camera angles and conditions unlike the public datasets.

Third, it runs a \textbf{3$\times$3 cross-dataset study} (training on CMOSE, DAiSEE, or both together; testing on each public test set plus the private set) and treats the private set as the deciding real-world test.
Engagement models do \textbf{not} transfer across datasets: off-diagonal QWK drops to near zero even when plain accuracy looks fine. The three contributions \emph{add up on the unseen private set}: training on both datasets together with the feature-group hybrid gives the best private-set result (QWK 0.379 against 0.285 for the best baseline, a bigger gap than in-domain).
The thesis argues that \textbf{quadratic-weighted kappa, not plain accuracy, must be the single primary measure that selects models on imbalanced engagement data}, with macro-accuracy and macro-MAE reported only as secondary balanced checks.

\vspace{0.5cm}
\noindent\textbf{Keywords:} student engagement recognition, affective computing, OpenFace, I3D, temporal convolutional networks, ordinal classification, class imbalance, cross-dataset generalisation.
